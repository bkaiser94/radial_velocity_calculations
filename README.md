# radial_velocity_calculations
Repository that houses all of my Goodman reduction code. It also allows limited handling of pre-processed GMOS data and plotting of data from other sources as well such as SDSS and TripleSpec. It also contains code that does other things such as radial velocity calculations. The name originated from my initial reason for reducing Goodman data, which was radial velocities. Ironically, it now is not so geared toward that function, but still retains it.
This code was not written with other users in mind as it was for my purposes.

It does contain my functions for correcting the sensitivity dip near H-beta, so those could probably be useful to other Goodman users.
